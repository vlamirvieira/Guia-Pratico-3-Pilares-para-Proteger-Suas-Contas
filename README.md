# Guia-Pratico-3-Pilares-para-Proteger-Suas-Contas
Este projeto apresenta um passo a passo para aumentar a segurança digital de suas contas mais importantes (e-mail, banco, redes sociais) utilizando três estratégias fundamentais.
Pilar 1: Configurar um Gerenciador de Senhas
Objetivo: Criar senhas fortes, únicas e impossíveis de decorar para cada conta.
1.	Escolha uma ferramenta: Opções como Bitwarden, 1Password, Dashlane ou Proton Pass.
2.	Instalação: Use extensões no navegador e o aplicativo oficial no celular.
3.	Senha Mestra: Crie uma senha única, longa (16+ caracteres) e fácil de lembrar apenas por você. Exemplo: Café!Montanha#2026Rio.
4.	Ação: Importe suas contas e troque senhas fracas por senhas geradas automaticamente pelo gerenciador.
🔐 Pilar 2: Ativar a Autenticação em Duas Etapas (2FA)
Objetivo: Impedir o acesso de invasores mesmo que eles descubram sua senha.
1.	App Autenticador: Instale Google Authenticator, Microsoft Authenticator ou 2FAS.
2.	Configuração: Nas contas (Gmail, Facebook, etc.), vá em Segurança -> Autenticação em duas etapas.
3.	Vinculação: Escolha "Aplicativo autenticador", leia o QR Code com o app e digite o código de 6 dígitos gerado para confirmar.
4.	Dica: Guarde os códigos de recuperação em um local seguro.
🌐 Pilar 3: Manter o Navegador Atualizado
Objetivo: Fechar falhas de segurança automaticamente.
•	Google Chrome/Edge/Firefox: Vá no menu de ajuda/configurações e clique em "Sobre" para verificar e forçar atualizações.
•	Safari (Mac): Mantenha o sistema operacional atualizado via Ajustes do Sistema.

•	[ ] Senhas repetidas trocadas por únicas.
•	[ ] 2FA ativado nas contas principais (E-mail, Banco).
•	[ ] Navegador configurado para atualizações automáticas.
